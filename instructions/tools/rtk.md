# Tool Usage: rtk (Token-Optimized Output)

`rtk` provides token-reduced wrapper output for shell & git commands.

## When to Use
- Use `rtk` commands when checking git status, diffs, or searching logs to preserve context window tokens.

## Usage Commands
- `rtk git status` — Compact git status view.
- `rtk git diff` — Compact git diff output.
- `rtk grep "<pattern>"` — Fast, token-efficient grep.
- `rtk log` — Summarized git log history.
