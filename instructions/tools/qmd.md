# Tool Usage: qmd (Quick Markdown Query)

`qmd` enables fast searching and querying across project Markdown documentation and knowledge bases.

## When to Use
- When locating documentation, guides, or specifications within the project docs directory.

## Usage Commands
- `qmd search "<query>"` — Search markdown docs for relevant topics or keywords.
- `qmd grep "<pattern>"` — Regex pattern search across all markdown files.
